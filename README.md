
# GraphQL API Development

## Objective
To develop a GraphQL API using Node.js and Express
and integrate it with a React frontend.

## Technologies Used
- Node.js
- Express.js
- GraphQL
- Express-GraphQL
- React.js
- GraphQL Request
- CSS

## Backend Features
- GraphQL Schema
- User Type
- Product Type
- Fetch All Users
- Fetch All Products
- Add New User
- Add New Product

## Frontend Features
- Add New Product
- Display Product List
- Display Product ID
- Display Product Name
- Display Product Price
- GraphQL API Integration

## How to Run

### Backend
cd graphql-lab-backend
npm install
node index.js

Backend URL:
http://localhost:5000/graphql

### Frontend
cd graphql-lab-frontend
npm install
npm start

Frontend URL:
http://localhost:3000

## Conclusion
Successfully developed a GraphQL API using Node.js
and integrated it with React. The application allows
users to add and retrieve product information using
GraphQL queries and mutations.
